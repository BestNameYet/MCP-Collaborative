# Tic-Tac-Toe Application Profile

This directory contains the normative requirements, architecture, prioritization, work ledger, and test plan for the Collaborative MCP tic-tac-toe profile.

The runnable local OpenAI plugin is [`../plugins/collaborative-tic-tac-toe/`](../plugins/collaborative-tic-tac-toe/). It bundles a STDIO MCP server through `.mcp.json` and is listed by the repository marketplace at `../.agents/plugins/marketplace.json`.

Mandatory governance files:

- `REQUIREMENTS.md`
- `DESIGN.md`
- `PRIORITIZATION.md`
- `REQUIREMENT_WORK_LEDGER.md`
- `TEST_PLAN.md`
